==================

A process is a running instance on any program..
Eg: 1.Running a python application

👉 Simple meaning
------------------
A process is a program that is currently running.

Program on disk → just a file (sleeping 😴)
Program in RAM + CPU executing → process (working 🏃️)

What is a Zombie Process? (Super Simple)
---------------------------------------

>> A Zombie process is a process that:
  ✅ Finished its work
  ❌ But still exists in the process table

>>In short:
  Dead process… but its entry is still there ☠️
  
 Use    :         ##ps aux 
 At stat colum : z or z+ it is a zombie process.
 
❓ Why Linux Keeps Zombie Processes

>> Linux needs to tell parent:
   How child exited
   Success or failure

Until parent collects this info:
👉 Zombie stays

>> This Zombie process should be killed otherwise it'll not let other processes to process..


👶 What is an Orphan Process?
------------------------------
>> An orphan process is:
   A process whose parent has died, but the child is still running

What Linux does?
  > Linux is kind 😄
  > It reassigns the orphan to:
    systemd (PID 1)
  So the process can continue safely.

Orphan Example (Step-by-Step)
-----------------------------

1️⃣ Parent process starts a child
2️⃣ Parent dies first
3️⃣ Child is still running
4️⃣ Linux says:

“Come here, I’ll be your new parent”

➡️ Child becomes orphan, adopted by PID 1

📌 Important:
👉 Orphan is ALIVE and RUNNING


❓ Can Orphan Become Zombie?
----------------------------
❌ Direct answer: NO
>> Because:
   Orphan = still running
   Zombie = already finished
   A running process cannot be a zombie.
   

⚠️ Where Confusion Comes From (Important!)
------------------------------------------
This CAN happen 👇

1️⃣ Child process becomes orphan
2️⃣ Orphan continues running
3️⃣ Orphan finishes execution
4️⃣ New parent = systemd
5️⃣ systemd immediately calls wait()

➡️ Result:
   Process is cleaned instantly
   NO zombie remains

So:
  Orphan dies cleanly, not as zombie
 
 🧠 Interview Gold Line ⭐
 -------------------------
 An orphan process is a running process whose parent has terminated, while a zombie process is a terminated process whose parent has 
 not collected its exit status. An orphan does not become a zombie because it is adopted by systemd, which properly reaps it.
